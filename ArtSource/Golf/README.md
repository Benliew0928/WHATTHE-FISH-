# Golf assets

The current game uses **Tidebloom Island**, an original tropical course inspired by the supplied cartoon concept.

- Editable master: `Tidebloom/Island_Tidebloom.blend`
- Authoring and integration guide: `Tidebloom/README.md`
- Layout, material and collision manifest: `Tidebloom/island-manifest.json`
- Generator: `Tools/Blender/build_golf.py`
- Live game export: `Game/Assets/_Game/Art/GolfIsland.fbx`
- Textures and Unity materials: `Game/Assets/_Game/Art/Golf/Tidebloom/`

`Legacy/ArtSource/Golf/Island.blend` and `island-dimensions.json` hold the September 23 flat placeholder archive. Their old 420 m square dimensions and 52-segment boundary no longer describe the current game environment.
