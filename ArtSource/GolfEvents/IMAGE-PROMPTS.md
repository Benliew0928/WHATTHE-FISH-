## Visual reference

The tornado's condensation body, cloud base and rotating ground dust follow
[NOAA's description of tornado visibility](https://www.nssl.noaa.gov/education/svrwx101/tornadoes/).
This is a game effect inspired by that structure, not a meteorological simulation.
