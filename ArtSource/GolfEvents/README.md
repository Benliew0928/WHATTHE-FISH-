# Golf event crab

`CrossingCrab.blend` is the editable master. `generate_crab.py` creates the
mesh, palette and articulated skeleton; `preview_crab.py` reimports the actual
FBX, checks dependencies and renders a static preview under ignored `Builds/`.
No paid generation service, stock model or external texture was used.

Provenance: geometry was generated by Codex-authored Blender Python, with
human-selected gameplay and asset direction. Treat it as an AI-assisted
procedural asset in any applicable submission disclosure. No Lux3D task ID is
claimed. See the adjacent `crab-provenance.json` for measured geometry and hash.

The delivery is [CrossingCrab.fbx](../../Game/Assets/_Game/Art/Golf/Events/CrossingCrab.fbx).
Its close/distant meshes contain 2,168 / 1,056 triangles, with 11 bones and
four solid materials. The runtime animates eight legs and two claws. Unity's
`GolfHazardBuild.Prepare` creates the two-LOD resource prefab and mobile palette;
the generated FBX, prefab, materials and their metadata belong in Git.

From the repository root, using the developer's installed Blender location:

```powershell
& $env:WTF_BLENDER_PATH --background --factory-startup --python-exit-code 1 --python ArtSource/GolfEvents/generate_crab.py
& $env:WTF_BLENDER_PATH --background --factory-startup --python-exit-code 1 --python ArtSource/GolfEvents/preview_crab.py
```

All project/output paths derive from the scripts' locations. FBX export uses
relative dependency paths and embeds no textures. Format-aware Blender checks
found no external image/library dependencies in the master or reimported FBX.
Blender may retain its authoring filename or saved UI history as nonfunctional
metadata; these do not supply a model dependency. Keep master quality intact.

## Event UI and vapor artwork

The three `*-master.png` files are generated raster artwork, separate from the
procedural crab model. See the exact [imagegen prompts and disclosure](IMAGE-PROMPTS.md).
Run `python ArtSource/GolfEvents/prepare_images.py` with Pillow to derive 768-pixel
badges and a 512-pixel vapor sprite. The current delivery totals **411,125 bytes**
before Unity packing, preserves alpha and keeps the smoke's smooth gradients.
The generator derives all paths from its own location. Native live timers sit
in the badges' blank blue capsules.
