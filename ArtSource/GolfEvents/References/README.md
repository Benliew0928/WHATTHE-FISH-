# Supplied tornado references

- `tornado-shapes-reference.png`: original user-supplied cartoon tornado asset collection.
- `tornado-growth-reference.png`: original user-supplied six-stage growth sheet.

Received 24 October 2026. Exact source PNG bytes are retained for authoring;
these contact sheets are not runtime billboards or Android resources. The active
implementation is editable native Unity geometry in `GolfTornadoFX.cs`, with
`GolfStormVolume.shader`, and reusable wind-ribbon material. No generated raster
replacement was used. The runtime 3D interpretation follows the hollow grey-blue
rolled funnel, white streamers, green leaves, orbiting stones and contact dust;
perspective and scene lighting mean it is not a pixel-identical copy of a 2D sheet.
