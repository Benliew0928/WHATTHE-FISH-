# Layered responsive welcome artwork

These editable PNG masters separate scenery and mascot from the native welcome
controls and the existing official logo. The built-in image generation tool
prepared both assets from the approved cable-car welcome reference. The final
mascot retains generated transparency. No text is embedded in these new layers.

The exact generation and alpha-repair prompts are in
[generation-prompts.json](generation-prompts.json). Dimensions, SHA-256 hashes,
alpha bounds and repository-relative delivery locations are in
[integrity.json](integrity.json). Master and delivery PNG bytes are identical;
Unity derives compressed platform textures from the delivery copies.

The panorama is 1983 by 793 pixels. Only scenery crops to cover the window;
mascot, logo and native controls retain their proportions and adapt independently.
The original approved welcome masters remain available in the parent folder.
