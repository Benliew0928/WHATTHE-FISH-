# Official game logo

![Official WHATTHE FISH? logo](WHATTHE-FISH-Logo.png)

**WHATTHE FISH? — Pocket Island** is the approved official logo for the game. Its artwork pairs the game's title with the tropical island, fishing, football, basketball, and golf.

The logo file is a 1254 × 1254 RGBA PNG with a transparent background. Keep **WHATTHE** together as one word and preserve the question mark whenever the title is typeset separately. The image is generated concept artwork; use the supplied PNG as the current official visual asset.

The nine unselected concepts and the former comparison gallery are retained in the local legacy archive at `Legacy/Docs/VisualDirection/LogoConcepts/`.
