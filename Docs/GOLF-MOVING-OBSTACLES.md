# Golf moving mechanisms — reverted

The user requested restoration of the previous Golf map on 18 October 2026.
All 21 moving mechanisms A–U have been removed from the active scene and
prefab. The generator hook, mechanism collision handoff, preview changes and
layer name were restored to the pre-feature source baseline.

The approved [design reference](../ArtSource/Golf/Course/MovingObstacles21.png)
is retained as a useful reference, not an active map configuration. The
superseded implementation, configuration, physics material and probe were
reviewed and archived with their Unity metadata in local archive batch
`20261018-184142-359-golf-mechanisms-reverted`. Earlier measurements remain
historical build records, not validation of the current map.

Existing tees, holes, terrain, fairways, bypasses, static props, sand, rough,
flags and six ponds remain unchanged. See [current Golf polish](GOLF-POLISH.md).
