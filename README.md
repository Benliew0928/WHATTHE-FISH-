# WHATTHE FISH?

WHATTHE FISH? is an Android-first game with football, basketball, golf, and fishing environments.

AI contributors must read [AGENTS.md](AGENTS.md) for the **strictly under-1-GB APK requirement** (1,000,000,000 bytes; updated 17 October 2026), visual-quality priorities and end-of-task cleanup. Before committing, run `Tools/Build/Check-TaskReady.ps1`; use `-RequireApk` when delivering an Android build. [Repository housekeeping](Docs/REPOSITORY-HYGIENE.md) explains what belongs in Git and how to recover archived files. The user stages, commits and pushes changes.

The official game logo is the **Pocket Island** design. See the [official logo and usage note](Docs/Branding/README.md).

The **sports home menu** uses the official logo and four energetic 2D sport cards. Each opens its own Create/Join, Explore Offline and Versus Bots page; Customize Venue and How to Play have separate global hubs. Room readiness, match conditions, venue previews, profile and settings remain integrated. See the [sports menu guide](Docs/SPORTS-MENU.md). The integrated game uses protocol **88**; friends need matching builds. See [teammate testing](Docs/TEAMMATE-TESTING.md) for sharing the complete Windows player and testing travel/match arrivals.

Football and basketball have small, plain bordered maps at bottom centre: blue is your team and red is the opponent. Fixed action slots switch with team possession, with loose balls defaulting to defense. Football and basketball use round, text-only thumb controls with press/release animation; utility and Sky-Sail controls use rounded pills. Fishing adds [six round skills with one choice from three shared cards](Docs/FISHING-ABILITIES.md), plus [Hold the Glow controls](Docs/FISHING-COUNTERSTEER.md): hold the glowing Left or Right button, switch with the fish and release both to ease tension, native sports fonts, fish badges and live rankings. Golf now uses the selected cream/navy/gold stickers, divided scorecard and framed **! Hold, then release** hint, with its existing rules and shot animation. See [Golf's editable HUD](Docs/GOLF-UI.md), [controls and maps](Docs/SPORTS-HUD.md) and the [resource cleanup](Docs/HUD-RESOURCE-CLEANUP.md).

The four islands now share the **Sky-Sail Circuit**: rideable group cabins, separate cable/tower/station modules, and distant 3D island views. Launch `Builds/WindowsFinal/Explore-SkySail.cmd` to start at a station. One host room travels together to one active island. See the [implementation guide](Docs/VisualDirection/WorldConnections/SKY-SAIL-IMPLEMENTATION.md) and [actual game gallery](Docs/VisualDirection/WorldConnections/GameReview/index.html).

The Windows player includes the selected F1/B1 **walkable coastal stadiums**: detailed cream-stone entrances, teal and timber trim, sea islands, connected spectator stairs and an open-air basketball arena. See the [actual EXE review gallery](Docs/VisualDirection/CoastalStadiums/index.html) and [implementation and validation notes](Docs/COASTAL-STADIUMS.md).

Golf and fishing now use **G2 Limestone Cove Links** and **L2 Limestone Garden Lagoon**, with detailed coastal materials, vegetation, facilities and walking routes. See the [27-view Windows gallery](Docs/VisualDirection/GolfFishingRefinement/GameReview/index.html) and [delivery evidence](Docs/VisualDirection/GolfFishingRefinement/GameReview/VALIDATION.md).

Open `Game` in Unity **6000.3.20f1**. Open `Assets/_Game/Scenes/Bootstrap.unity`, then press Play. The football stadium, open-air basketball arena and golf island are Blender assets. The shared athlete is the approved Meshy 6 Lite Rainbow Sprinter, prepared in Blender. There are no spectator NPCs.

For a fresh clone, install Git LFS, run `git lfs install` and `git lfs pull` before opening the Unity project so Blender masters, FBX models and textures are available. Install the matching Unity Editor and Windows Build Support; Android builds also need Android Build Support. `Builds/` and `Legacy/` are local folders excluded from Git; teammates receive the Unity project and editable resources, then build their own Windows player with `./Tools/Build/Build.ps1 -Target Windows`. See [setup](Docs/SETUP.md) for alternate editor locations and [build tools](Tools/Build/README.md) for the retained scripts.

The [30 October optimization and final delivery report](Docs/FINAL-OPTIMIZATION-2026-10-30.md) records current measurements, verification and remaining limits.

## Controls

Fishing: use `Builds/WindowsFinal/Explore-Fishing.cmd`, or choose **Let's play → Fishing → Explore offline**. Near a coloured pier, drag the camera to aim the centre reticle; teal identifies an available fish. Tap Cast, react to the gold fish **!** with Hook, then **hold the glowing Left or Right button**. Switch with the glow and release both to cool tension. The fish-marker/gold-band meter returns, with no tap window or one-attempt sweep. Continuous winding uses physical line forces; Follow fight framing, Eye-level control, rod grip, rope, swimming and splashes remain. Arrival selects Follow; Island View is a manual settings choice with a wider player-anchored view. Reduced Motion retains the preferred view. The shared four-page tutorial reuses the live meter, skill icons and buttons and contains no keyboard guides. Small/medium/large catches earn **2/5/10** points, with a once-per-minute **+3 Wanted** bonus in scored rounds. The host starts the default three-minute **Round** directly, without Ready, mode selectors or a nickname field. Highest points wins; equal totals share a rank. All five piers share a public pool of 30 fish using existing models and LODs. Before each timed round, everyone sees the same three skill cards and picks one reusable skill. Its contextual button recharges after use. Hook alerts, physical surface splashes, live ranks, a confirmed points landing card/sound, optional vibration, and the closeable round-results card remain. Matching online peers require protocol **88**. See [hold controls, host validation and camera](Docs/FISHING-COUNTERSTEER.md), [full rules](Docs/FISHING-MINIGAME.md) and [editable timer/layout](Docs/FISHING-HOOK-CUE.md). Golf retains `Explore-Golf.cmd`; the [Blender source guide](ArtSource/RefinedIslands/README.md) covers editable island masters and modules.

Landscape: left thumb stick moves; push it fully to run. Drag on the right to look. Tap **Camera** to cycle first person, third person and stadium views. Football uses a high perspective broadcast view; basketball uses a closer angle with basket-aware framing. See [stadium camera design](Docs/STADIUM-CAMERAS.md). On Windows: WASD, Shift, right mouse drag, C. Escape returns to the menu/waiting room. A guest leaving an environment leaves the room; the host can return everyone to the waiting room.

Basketball: walk near the ball to pick it up and dribble. **Hold E / Shoot** to raise the ball and aim while moving at half speed. The needle loops through the green band, speeding up with basket distance (**0.84–0.42 s per sweep**); release in green, or **drag to Cancel / press X** to resume dribbling. The larger 30 cm ball uses physical arcs, rim/backboard rebounds, 2/3-point scoring and responsive nets. A translucent teal/gold boundary keeps players in and ripples on player contact or a ball passing through. **Free roam** allows intentional station travel. **Slide Shoot up for Dunk or down for Layup**. When READY within the 4 m approach range, release immediately: no timing, 100% unblocked dunk or an 85% layup roll. An unavailable finish uses normal shot charging and timing. Desktop uses **E + Up / Down**. [Close finishes](Docs/BASKETBALL-FINISHES.md) validate the approach and jump path, animate takeoff through landing and score through physical rim crossings. **Hold Q / Pass** to aim and charge, then release; Up/Down or a vertical touch swipe selects loft/bounce. The shared curved preview shows the planned flight. See [passing controls](Docs/BASKETBALL-PASSING.md). Normal shot chances vary continuously with timing, distance and guard pressure; green timing improves the chance without guaranteeing a basket. See [shot odds](Docs/BASKETBALL-SHOT-ODDS.md). **Hold F / Steal** repeats a timed swipe; a successful strip animates both players and knocks the ball loose for anyone to recover. Range, facing, shielding and dribble timing decide contact. Possession switches the fixed action slots: defenders hold **Q / Defend** to pressure guard, tap **E / Block** for a standing reach, or use **Space / Jump Block** (also drag Block upward and release) against higher balls. Shoot and Pass appear whenever your team holds the ball, with use limited to the carrier; loose balls and opposing possession show defense. Basketball squads alternate automatically as players join. A block succeeds through timed, reachable hand contact and creates a physical loose ball. See [defense controls and animation](Docs/BASKETBALL-DEFENSE.md). The host controls physics, scoring and net events for the room. See [basketball controls, calculations and validation](Docs/BASKETBALL-GAMEPLAY.md) and the [latest build record](Docs/BUILD-SIZE.md).

The room system uses Unity Multiplayer Services sessions, Relay, Unity Transport and Netcode for GameObjects. Offline exploration requires no Unity account or internet connection. Online rooms require your cloud project to be linked and services enabled.

The linked Unity cloud project supports internet rooms through Relay; create/join has been tested. Read `Docs/VERIFICATION.md` for the test coverage and phone checks still pending. Launch the Windows executable normally, without diagnostic arguments, for interactive play.

The prototype includes exploration, character art, networking and sport gameplay. The Rainbow Sprinter is one shared look for now; character appearance controls are paused until the model has separate, swappable parts. Football now has a basic kickable physics ball: approach it and tap/release F or Kick for a light kick, or hold and release for a charged kick. A slow free ball can attach in front of one controller’s feet and follow movement/turns, including 180° reversals. The controller moves 25% slower and cannot jump or tackle. Kicking or a successful opponent tackle releases a free physical ball; ordinary movement no longer pushes it. See [the prototype guide](Docs/FOOTBALL-PROTOTYPE.md). Casual programmed football and basketball bots support 2v2 through 5v5 through **Play vs bots** or host room filling. Learned AI training is retired; see [programmed bots and cleanup](Docs/PROGRAMMED-BOTS.md). Basketball supports dribbling, timed shooting, layups, dunks, passing, pressure guarding, standing and jump blocks, repeated steal attempts, physical loose-ball contests, shared practice scoring and net response. Choose Basketball → Explore offline to play with the ball. Arena customization provides four center logos, four accent palettes, a name, and a reset control. Hosts share their selection with guests; custom-image importing is deferred.

Choose Golf → Explore offline, then **Start game**. All five cups stay open while each player completes their own sequence. Walk within **3 metres** of a stationary ball and use **Aim / G** to lock the stance. Grab the ball handle at the green top of the power rail, drag down to increase power, then release to strike; dragging up reduces power. The preview starts at 30% until a drag selects power, and releasing at zero does not strike. Putt is chosen automatically within 12 horizontal metres of the ball owner's current cup; Swing is chosen farther away. The gold target marks a putt's stopping point or a swing's first touchdown. **Cancel / X** restores walking without adding a stroke. Ownership stays fixed; only the hitter gains a stroke. Wrong cups and out-of-bounds shots recover to the last shot position. The first finisher starts one shared 30-second countdown; finishers rank by total strokes, then elapsed finish time, ahead of DNF. Existing walking, cameras, shoreline containment and carts remain available. See [the current drag control](Docs/GOLF-DRAG-POWER.md) and [Golf rules and authority](Docs/GOLF-MINIGAME.md).

For the current Windows coastal redesign, see `Docs/COASTAL-STADIUMS.md`. `Docs/RALLY-INTEGRATION.md` records the earlier indoor-arena milestone. Golf milestone results remain in `Docs/GOLF-VERIFICATION.md`; the prior basketball milestone is recorded in `Docs/BASKETBALL-VERIFICATION.md`.

Football also has faster walking/running and kicks, **Dash / left Ctrl** with stamina, and **Pressure / Q** to contain an opposing carrier. Kick and Pressure share a possession-aware slot; Tackle appears on defense. The host controls stamina and movement. See [football pace, stamina and pressure](Docs/FOOTBALL-PACE-AND-PRESSURE.md).

Football has a separate host-started timed match with 10-second capacity-limited team selection, whole-ball goals, score/restart, seamless golden-goal overtime and result display. Formal matches require even participation (2–10 players including bots); Play vs bots and host bot filling support 2v2 through 5v5. Players can keep walking/running after the final result, with scores locked. See [match rules and checks](Docs/ROOM-MATCH-RULES.md) and [casual bots](Docs/PROGRAMMED-BOTS.md).

Golf round polish: events start every 60 seconds and cover all five before
repeating. Hole 1 stays first, with a shared random order for the other holes.
Larger tornadoes throw farther; crabs pursue nearby balls with stronger claw
hits. Tap to skip ball-flight follow. Golf and Fishing awards reuse the existing
court characters and animations. Fishing skills are stronger, and the stray
pre-hook arrow above Jump is removed. See [Golf details](Docs/GOLF-HAZARDS.md)
and [Fishing skill values](Docs/FISHING-ABILITIES.md).
